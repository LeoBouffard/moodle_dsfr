Pour mettre en place le thème :
- Télécharger le .zip
- se mettre à la racine de moodle
- mettre le .zip dans le dossier "theme"
- deziper le .zip avec unzip moodle_dsfr-5.1.zip
- renommer le dossier moodle_dsfr-5.1 en moodle_dsfr avec : mv moodle_dsfr-5.1 moodle_dsfr
- normalement le thème apparait
